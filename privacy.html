OwnScreen data use

Capture and storage

OwnScreen records the display, window, tab or rectangle you select. Camera and microphone media are included only when enabled. Recordings and screenshots are stored in your browser profile. You can download them or grant the Chrome extension access to a folder you choose. If you pick a synced folder, its sync service handles that copy. Browser controls and settings are saved locally.

Optional online storage

If you connect OneDrive or Google Drive, recordings you choose to save are uploaded directly from your browser to your own account, into a folder named “OwnScreen”. They do not pass through any OwnScreen server. Sign-in happens on Microsoft’s or Google’s own page; OwnScreen never sees your password. It receives an access token limited to files (for Google Drive: only files OwnScreen created), stored only in your browser profile. “Disconnect” in the settings deletes it. A share link is created only when you ask for one, with the access you choose, and you can remove it in OneDrive or Google Drive at any time. Data received from Google APIs is used only to save and share your own files and follows the Google API Services User Data Policy, including the Limited Use requirements.

Optional AI requests

When you run an AI action, OwnScreen sends the image or text you selected and your prompt to OpenAI, Anthropic or OpenRouter, or to your configured local Ollama instance. OpenRouter can route a request to a model provider. Your key is submitted only to the selected service and kept in the open assistant dialog. Each service has its own terms and data handling. You can use recording, editing and downloads without AI.

Accounts and telemetry

The public OwnScreen builds require no OwnScreen account and contain no analytics or advertising code. The site hosting the static app can receive ordinary page requests.

Deleting your data

Delete recordings with “Delete recording” in OwnScreen. Files already saved to OneDrive or Google Drive stay there until you delete them in that service. Uninstalling the extension removes all data it stored in your browser.

Browser extension permissions

OwnScreen uses browser capture permissions to provide the features you request. The Chrome Web Store version uses data for its stated recording, editing and optional analysis features in accordance with the Chrome Web Store User Data Policy, including the Limited Use requirements.
